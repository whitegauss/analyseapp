## 先に知っておくと事故らないこと

**赤くなったテストが「直すべきバグ」を指しているとは限らない。** 既知のバグは、直す前に「いまの壊れた挙動」をテストで固定してある。バグを直すとそのテストが落ちるが、それは**成功のしるし**であって、修正を戻す理由ではない。詳しくは [testing.md の「現状固定テスト」](testing.md#現状固定テスト)。
